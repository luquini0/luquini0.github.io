One page for your team: phishing and scams in 2026

Print this, pin it up, and agree on it before the bad day. Five scams, one rule each.

1. ClickFix: "paste this to prove you're human"

A web page or message shows a fake error or CAPTCHA and tells you to press Win+R (or open a terminal) and paste something it has just copied for you. That is you running the attacker's command.

Rule: no real website needs you to paste a command to read a page. Close it and tell IT.

2. QR codes

A QR code hides the address. Attackers stick fake ones over real ones or put them in emails and PDFs to avoid link filters ("quishing").

Rule: read the address your phone shows before opening it. Never sign in from a QR code you did not expect; type the site's address yourself.

3. Cloned voices and urgent calls

Short audio samples can be enough to imitate someone's voice. A call from "the boss" or "a relative" asking for money, gift cards or a quick transfer is a classic.

Rule: hang up and call back on a number you already had. Agree on a code word with family. Payments and bank-detail changes need a second person, whatever the voice says.

4. Passkeys over passwords

A passkey is tied to the real site's domain, so a look-alike site cannot use it, and there is no password to type into a fake page or reuse. Turn them on where you can (email, cloud storage, code host, bank) and keep a recovery method.

Rule: where passkeys exist, use them. Where they do not, use a password manager and app-based or hardware MFA.

5. Urgency, secrecy, authority

Almost every scam pushes at least one of these: "right now", "don't tell anyone", "I'm the CEO". The pressure is the signal.

Rule: pause, verify through a second channel, then act.

If you already clicked or pasted

  1. Disconnect the device from the network.
  2. Tell IT or the owner immediately. Nobody gets blamed; speed matters.
  3. Change passwords from a different, clean device.
  4. Note what you saw: the page, the message, what you typed.

Pin-up checklist

  • I never paste commands from a web page.
  • I check the address behind a QR code.
  • I call back on a known number and use the family/team code word.
  • Money and bank-detail changes need two people.
  • I use passkeys where available.
  • I know who to tell, and I tell them fast.
